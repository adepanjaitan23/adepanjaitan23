## Ringkasan

Saya membangun perangkat lunak dengan pendekatan riset terapan: merumuskan masalah, menyusun hipotesis, menguji lewat prototipe, lalu mengiterasi sampai solusi stabil dan terukur. Minat utama saya berada pada persilangan pengembangan aplikasi, analitik data, sistem cerdas, serta integrasi perangkat (IoT).

### Fokus Saat Ini
- Pengembangan aplikasi berbasis Python (backend, data pipeline, eksperimen model)
- Penerapan model statistik dan machine learning pada kasus nyata
- Sistem IoT: komunikasi perangkat, otomasi, dan inferensi ringan (TinyML)

### Cara Saya Bekerja
- Berangkat dari metrik dan batasan (latensi, akurasi, biaya komputasi)
- Dokumentasi eksperimen dan keputusan teknis
- Desain modular agar mudah diuji dan dipelihara
